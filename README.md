# ⏳ Cydata Event Timer Website

A simple and responsive event countdown website built for **Cydata**, an event conducted by the MCA Department as part of **SAHYA**, the main college fest of Marian College Kuttikkanam.

---

## 📌 About the Project

This website displays a live countdown timer for the Cydata event.  
It helps participants easily track the remaining time until the event starts.

The project is built using basic web technologies and hosted using GitHub Pages.

---

## 🎉 About the Events

### 🌄 SAHYA
SAHYA is the official college fest of Marian College Kuttikkanam.  
It includes various cultural, technical, and creative events conducted by different departments.

### 💻 Cydata
Cydata is a technical event organized by the MCA Department under SAHYA.  
This website was created to support and promote the event digitally.
